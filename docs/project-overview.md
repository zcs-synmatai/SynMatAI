## 布局与交互

项目标题横跨内容区，左侧304px项目Agent，右侧按AI摘要与个人待办、成员与近期报告、紧凑甘特图三层组织。知识库和项目资料不再作为概览卡片，资料保留标题入口。桌面聊天输入固定底部，两侧分别滚动；不足1280px时Agent收成入口，可展开覆盖。管理与详情共用唯一右抽屉，Esc关闭、键盘可操作并返回触发位置。

AI概览根据同一快照显示核心判断、关注事项、建议行动、来源覆盖和更新时间。刷新不会在资料未变化时虚构新结论；查看依据能到T24/T26，追问会把来源带到Agent输入。报告交付后摘要、甘特状态和待办同步；失败报告可交付，但不会自动入选路线、放行或判定材料达标。

甘特图使用同一滚动容器实现冻结任务列和日期区垂直同步，支持阶段展开、周/月、今天、适应项目周期、横向滚动、周末底色、今日线与评审标识。计划与任务状态分开，不绘制臆测实际百分比。默认只展示6个折叠阶段，点击按需展开任务，任务区最大230px内滚动。选中任务时才显示其相关依赖。R1—R4为同图展示筛选，共用任务和汇合条件不减少。查看完整流程进入已有流程页。

日期建议显示原日期、新日期、原因和受影响下游，先保存待确认草稿；确认采用只改变所选任务，不自动平移下游。撤回、取消不改有效排程。

## 成员与知识库

成员支持按姓名/角色搜索、多选已有组织示例用户、分别指定角色、编辑业务角色与成员管理权限。普通成员预览只读。移除前明确接手人或待分配；负责人必须先移交。任务不会消失，责任人、头像、人数、待办和AI联系人联动。只改变本项目成员关系，不删除组织账号。

知识库分已关联/可关联，支持搜索名称/范围/标签、确认关联、预览演示条目、Agent检索开关及确认解除关联。原来源无权限或失效时不允许预览、关联或提供给Agent。关闭开关不解除关联；解除关联不删除原库。关联数、可用来源数和AI覆盖联动。知识库和本项目SOP/报告资料分开。
