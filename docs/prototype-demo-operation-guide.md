# SynMatAI 用户操作指南

更新日期：2026-11-15。对应“高导热凝胶开发示例”与当前工作区、项目管理和审批中心。

本指南介绍如何在 SynMatAI 原型中创建和管理材料研发项目、推进任务、与 Agent 协作，以及查看项目流程、文档、实验和模拟计算内容。

当前版本为交互原型。页面中的 Agent 回复、自动调研、实验过程和模拟计算用于展示产品使用方式，不代表已经连接真实 AI、实验设备、科学计算服务或企业审批系统。

## 1. 登录系统

访问系统地址后，首先进入登录页面。

1. 输入管理员提供的账号和密码。
2. 点击“登录并进入”。
3. 登录成功后，系统会继续打开原本访问的页面。

登录状态默认在一定时间后失效。需要主动退出时，点击主菜单底部用户信息右侧的“退出”。

如果提示账号或密码错误，请检查输入内容，或联系管理员重新获取登录信息。

## 2. 认识页面布局

登录后，页面主要分为以下区域：

- **主菜单栏**：切换项目列表、项目工作区、实验工作台和审批中心。工作区中悬停“项目工作区”图标可快捷切换项目。
- **项目内对话列表**：查看并切换当前项目中的任务对话、工作包对话和项目级对话。
- **Agent 对话栏**：与当前任务对应的 Agent 协作，查看任务说明和发送消息。
- **工作预览区**：查看任务资产、Markdown 文档、实验 ELN、模拟计算或项目流程画布。
- **演示说明**：根据当前页面和任务显示操作提示。卡片可以拖动、最小化和恢复。

部分区域之间有可拖动的分隔线，可以根据当前工作调整对话区和预览区宽度。

## 3. 项目列表

首次进入系统时默认打开“项目列表”。项目列表展示项目名称、当前阶段、当前工作、负责人和最近更新时间。

### 3.1 进入项目

每个项目提供两个入口：

- **工作台**：进入当前进行中的任务，继续对话和处理任务资产；点击项目条目主体也进入这里。
- **项目概览**：查看总览、项目资产与项目管理；“进入项目流程”按钮打开流程画布。

系统会记录项目最近的进度。重新进入项目时，会优先打开当前进行中的工作。

### 3.2 搜索项目

在项目列表顶部的搜索框中输入项目名称、负责人或当前任务，可以快速筛选项目。

### 3.3 新建项目

1. 点击页面右上角“新建项目”。
2. 填写项目名称。
3. 填写负责人和项目简介；项目简介可以暂时留空。
4. 点击“创建并开始需求确认”。

创建完成后，系统进入新项目的第一个任务，引导补充项目基础信息。

新项目开始时只创建项目立项阶段。研发和量产阶段在尚未规划时显示“待规划生成”，不会提前创建具体任务。

### 3.4 删除项目

普通项目可以在项目列表中删除。删除项目会同时删除该项目在当前浏览器中保存的流程、对话、文档和任务进度，且无法恢复。

内置示例项目受到保护，不能删除。

内置“高导热凝胶开发示例”保留已完成的立项记录，并默认从 T31“确认BLT、硬度与稳定性”的实验工作台体验 ELN。要从需求确认开始，请新建项目。

## 4. 项目概览

项目概览用于快速了解项目当前状态，包括：

- 项目整体进度和当前阶段。
- 当前重点工作和待处理事项。
- 最近产生的项目文件。
- 项目团队成员。
- 核心指标达成路径。

“核心指标达成路径”将日期、阶段技术方案和指标结果显示在同一张图中：

- 实线表示已经完成的阶段结果。
- 虚线表示尚待验证的计划目标。
- 每个数据点对应一个阶段技术方案及其指标结果。

图表中的数值和材料结构为原型示例，不代表真实项目结论。

## 5. 新项目的标准流程

新项目从“项目立项”阶段开始，依次包括：

1. 需求确认。
2. 技术调研。
3. 项目立项。
4. SOP 审批。

完成 SOP 审批后，系统生成首个研发阶段的工作包和任务。

### 5.1 需求确认

进入需求确认任务后，Agent 会提示补充：

- 项目需求。
- 约束条件。
- 预期产出。

您可以直接使用自然语言描述，不需要严格按照固定格式填写。提交信息后，系统会整理形成“项目基础信息.md”。

操作步骤：

1. 在对话输入框中填写项目背景和目标。
2. 发送消息。
3. 检查 Agent 整理出的项目基础信息。
4. 在右侧资产区打开“项目基础信息.md”进行查看。
5. 确认信息无误后，选择启动技术调研。

### 5.2 技术调研

技术调研包含两个并行任务：

- 梳理技术路线与证据缺口。
- 形成技术调研报告。

两个任务会同时进入进行中。完成其中一个任务不会直接完成整个工作包；系统会切换到另一个尚未完成的任务。两个任务全部完成后，技术调研工作包自动更新为已完成。

技术调研产生的文档会显示在“本对话产生的资产”中，也可以在“项目资产”页面统一查看。

### 5.3 项目立项

技术调研完成后进入“立项材料准备”。查看材料、补充文件并完成任务时，系统提醒立项需要审批；原型可以点击“模拟审批通过并继续”，记录模拟通过结果后进入 SOP 节点。

### 5.4 SOP 审批

SOP 审批用于确认项目后续研发工作如何拆分，按普通“流程变更—阶段”审批规则处理。未配置审批时确认后生成研发；配置了审批角色则先提交申请，通过后生成研发阶段1，并进入首个可以执行的任务。

原型中的审批只更新本地项目状态，不代表真实审批或授权已经完成。

### 5.5 客户准入与下一研发阶段

每个研发阶段的最后一个工作包为“客户准入”，用于收集本轮反馈并确认阶段任务。完成确认后，系统会询问是否启动下一研发阶段：

- 选择“启动研发阶段 2”：按研发阶段 1 的工作包和任务结构生成新一轮节点，并进入首个可执行任务。
- 选择“暂不启动”：保留本轮反馈和规划决定，不创建新的研发节点。

研发阶段 2 的状态和资产独立保存，不会覆盖研发阶段 1 的记录。

## 6. 项目工作区

项目工作区是处理具体任务的主要页面。页面左侧为 Agent 对话，右侧为当前任务的工作预览。

### 6.1 查看当前任务

对话栏顶部显示：

- Agent 名称和当前任务名称。
- 工作包编号和任务编号。
- 当前任务的状态和任务上下文。

任务名称较长时会自动省略，鼠标悬停可以查看完整内容。

### 6.2 切换对话

点击 Agent 标题左侧的对话列表图标，可以展开或收起项目内对话列表。

对话列表收起时，将鼠标停留在图标上，会显示临时浮层。您可以直接在浮层中切换对话，也可以点击图标重新展开完整列表。

对话可能对应不同层级：

- **SuperAgent项目总工**：固定在“新建对话”下方，与 Supervisor Agent 讨论项目整体安排。
- 阶段对话：与 Supervisor Agent 讨论某个阶段。
- 工作包对话：讨论某个工作包的目标、输入和交付。
- 任务对话：与专业 Agent 处理当前具体任务。

选择项目、阶段或工作包的 Supervisor 对话，右侧自动切换到相应流程；选择具体任务对话则切换到任务工作台。列表始终保留全部对话，搜索图标可展开搜索框。“新建对话”用于创建工作流对话，画布多选节点也可创建带节点上下文的新对话。

### 6.3 发送消息

1. 在底部输入框中输入内容。
2. 按 Enter 发送消息；使用 Shift + Enter 换行。
3. 消息发送后，输入框会保持焦点，可以继续输入。

输入框下方会显示当前消息关联的任务或上下文。

### 6.4 查看任务资产

右侧“本对话产生的资产”展示当前任务产生或需要补充的文件。

- 点击“打开”查看文件。
- 点击“上传文件”选择本机文件。
- 双击资产列表中的 Markdown 文件可以直接打开预览。
- 点击资产弹窗以外的区域可以关闭弹窗。

未上传文件会显示为“待上传”。原型中的上传只保存在当前浏览器，不会发送到真实服务器。

### 6.5 使用多页签工作预览

文档、节点资产、实验 ELN 和模拟工作台会以页签方式打开。

- 点击页签切换内容。
- 点击页签右侧关闭按钮关闭当前内容。
- “节点资产”是默认且不可关闭的页签。
- 关闭文档、ELN或模拟页签后，仍可切回节点资产查看文件及“完成任务”按钮。

### 6.6 调整页面宽度

拖动 Agent 对话栏和工作预览区之间的分隔线，可以调整两侧宽度。

- 普通任务未打开文件时，对话区默认占据较大空间。
- 打开文档后，预览区会获得更多空间。
- 实验和模拟计算任务打开时，专业工作区默认约占可用宽度的 80%。

### 6.7 完成任务

确认当前任务内容后，点击右侧“完成任务”。如果配置了对应完成审批，先提交申请，由审批人通过后再更新任务与下游状态；驳回后继续补充。

系统会：

1. 将当前任务更新为已完成。
2. 如果工作包中还有并行或未完成任务，切换到其中一个任务。
3. 如果当前工作包全部完成，将工作包更新为已完成。
4. 进入下一个已满足前置条件的工作包或任务。

多个下游分支同时满足条件时，会同时进入进行中；工作台只选择其中一个作为当前页面，不影响其他分支状态。

## 7. 项目流程

项目流程以画布方式展示项目的真实依赖关系。页面提供全局、阶段和任务三种视图。

### 7.1 全局视图

全局视图展示项目立项、研发、量产等阶段之间的关系。尚未规划的阶段显示“待规划生成”。

### 7.2 阶段视图

阶段视图展示当前阶段内的子阶段和工作包。工作包卡片显示名称、编号、状态和负责人信息。

### 7.3 任务视图

任务视图展示工作包内部的任务、输入文件、输出文件和依赖连线。

文件节点只表示资料输入或任务产出，不参与“待开始、进行中、已完成”的状态传递。

### 7.4 切换流程层级

- 单击顶栏节点：定位到对应阶段或工作包。
- 双击画布中的阶段或工作包：进入下一层流程。
- 双击顶栏中的当前工作包或阶段图标：返回上一层流程。
- 点击右上角视图按钮：直接切换全局、阶段或任务视图。
- 点击左上角后退、前进图标：恢复此前浏览位置，不撤销节点修改或审批。

### 7.5 浏览画布

- 在画布空白区域拖动可以平移。
- 使用底部缩放控件放大或缩小。
- 点击“适应画布”显示完整流程。
- 改变页面区域宽度后，画布会自动重新适应可用空间。
- 使用画布两侧箭头可以切换相邻阶段或工作包。

### 7.6 查看和编辑节点

鼠标悬停或选中阶段、工作包和任务节点时，会显示对应信息卡片。

- 未开始和进行中的工作包、任务可以编辑。
- 可以修改任务名称、类型、负责人、执行方式、状态、交付要求和输入输出文档。
- 已完成节点保持只读，不能重新连接进入该节点。
- 已完成节点仍可以连接到新的下游节点。
- 新节点可以没有下游节点，作为当前流程的终态节点。

### 7.7 新建任务和连接节点

从任务节点的连接点拖出连线，并在画布空白位置释放，可以创建下游节点。

可创建的节点类型包括：

- 结果文件。
- 实验节点。
- 模拟计算。
- 分析节点。
- 调研节点。
- 临时任务。

新建工作包默认只包含一个默认任务，您可以继续编辑或添加下游任务。

### 7.8 使用 Agent 快捷菜单

任务视图顶部提供分析、调研和 DOE Agent 快捷入口。

将 Agent 拖到画布上，可以直接创建相应类型的任务。进行中的部分任务会显示“Agent 工作中”状态，用于表示当前任务正在由 Agent 协作处理。

## 8. 工作包和项目级协作

除了具体任务，您也可以与 Supervisor Agent 讨论项目或工作包。

1. 在流程中将鼠标停留在阶段或工作包节点上。
2. 在节点信息卡片顶部选择“打开 Agent 协作”。
3. 系统切换到对应层级的 Supervisor Agent 工作流对话，右侧展示该节点的流程上下文。
4. 默认对话记录展示 WorkerAgent 委派及“已完成／进行中”演示状态。要查看具体任务资产或 ELN，请选择任务对话。

使用对话列表可以随时返回具体任务对话。

## 9. 实验任务与 ELN

新建实验类型任务，或把未完成任务修改为实验类型时，系统会自动创建并关联一条实验记录。

双击实验节点，或点击节点卡片中的 Agent 协作入口后，工作区右侧会打开：

- 节点资产。
- 实验 ELN。

ELN 用于查看和记录实验方案、执行记录、样品、测量结果和可见资产。自动创建实验记录只表示已建立实验容器，不代表实验方案已经确认或实验已经执行。

## 10. 模拟计算任务

双击模拟计算节点后，工作区右侧会打开：

- 节点资产。
- 模拟工作台。

模拟工作台展示计算依赖、材料参数、构件模型、任务调度和结果分析。可以查看或修改演示参数，但当前原型不会执行真实科学计算。

## 11. 实验工作台

主菜单中的“实验工作台”集中展示当前项目的实验记录。

可以查看：

- 实验状态和关联任务。
- 采用的方案及版本。
- 制备批次、样品和测试记录。
- 实验产生的项目资产。

从任务自动创建的实验会保留与原任务的关联，便于从流程追溯实验记录。

点击实验名称或进入按钮后，系统会进入该实验关联的任务工作台。右侧默认保留“节点资产”页签，并同时打开“实验 ELN”页签；关闭 ELN 后仍可继续查看任务资产和完成当前任务。

## 12. 项目资产

从项目概览切换到“项目资产”。左侧 Copilot 用于讨论当前项目资料，右侧文件按阶段、工作包和任务组织，便于沿项目流程查找交付物。

“项目资产”集中管理项目中的文档和记录，包括：

- 项目基础信息。
- 技术调研报告。
- SOP 和审批材料。
- 实验记录。
- 模拟计算文件。
- 任务产生的其他文档。

资产会保留来源任务、所属阶段和关联关系。打开资产后，可以查看文档内容及其版本信息。

### 12.1 项目管理

在项目概览切换“项目管理”，左侧添加成员并指定项目负责人、Leader、+1、+2，右侧配置流程变更、工作流转和项目审批。按阶段、子阶段、工作包、任务勾选审批角色并保存；工作流转区分启动、完成。项目审批还支持项目本身。

角色按顺序审批，同一人员合并；全部不勾选则直接生效。必审角色需要配置人员。规则变化不改变已经提交的审批链。当前已接入任务完成、任务变更、工作包及依赖变更、立项模拟通过和SOP确认；阶段/子阶段独立启动等暂仅保留规则配置。

### 12.2 审批中心

1. 从主菜单进入“审批中心”，选择待我审批、我已处理或我发起的。
2. 打开申请，查看项目、申请人、原因、变更前后和审批链。
3. 点击“预览项目流程”查看只读上下文，或进入节点工作台查阅材料，再用“返回审批详情”继续处理。
4. 填写意见并通过或驳回；驳回必须说明原因。多级审批全部通过后才应用操作。

系统内置8条示例审批。默认林晓有3条待审、2条已处理和3条我发起的；切换演示身份可体验逐级处理。标记“示例”的申请只改变审批记录，不修改示例项目研发进度；实际发起的操作申请按配置生效。

## 13. 演示说明卡片

页面中的“演示说明”卡片会根据当前页面、工作包和任务自动更新。

- 拖动卡片标题区域可以移动位置。
- 点击最小化按钮可以收起内容。
- 点击收起后的卡片可以恢复正常大小。
- 切换页面或任务后，提示内容会自动更新。

内置示例项目首次进入时可能显示蒙版式新手引导。按照提示依次了解主菜单、对话列表、工作预览区、多页签和流程画布即可。

## 14. 状态说明

项目中的工作包和任务主要使用以下状态：

- **待开始**：前置工作尚未完成，当前任务不能开始。
- **进行中**：前置条件已满足，可以处理当前任务。
- **Agent 工作中**：任务处于进行中，并显示 Agent 协作状态。
- **已完成**：任务内容已确认，节点保持只读。

状态由任务依赖和用户操作共同推进。文件节点不会阻止下游任务开始。

## 15. 数据保存与功能边界

当前原型的数据保存在浏览器本机，请注意：

- 切换项目或刷新页面会保留当前进度。
- 清除浏览器站点数据后，新建项目和操作进度可能丢失。
- 在其他电脑或浏览器中打开，不会自动获得当前浏览器中的项目数据。
- 上传文件、Agent 回复、实验和模拟计算均为本地演示逻辑。
- 原型不代表已完成企业权限、审计、真实 AI、实验设备或后端数据库集成。

## 16. 常见问题

### 登录后仍然停留在登录页

检查账号密码是否正确，并确认浏览器允许当前站点保存 Cookie。必要时重新打开页面或联系管理员。

### 进入工作区后不是预期任务

返回“项目列表”，确认当前项目后重新点击“工作台”。系统会进入当前项目第一个进行中的任务。

### 找不到对话列表

点击 Agent 标题左侧的对话图标。列表收起时也可以将鼠标停留在图标上打开临时切换浮层。

### 关闭文档后如何继续任务

点击默认“节点资产”页签，回到本对话产生的资产和“完成任务”按钮。该基础页签不能关闭。

### 流程节点无法编辑

已完成节点为只读状态。只有待开始或进行中的工作包和任务可以编辑或删除。

### 实验节点提示未关联实验

新建或修改为实验类型后，系统会自动建立演示实验记录。如果仍未关联，可以重新保存节点类型后再次打开。

### 页面内容与预期不一致

先返回项目列表确认当前项目，再重新进入工作台或项目流程。刷新页面不会主动切换当前项目和节点。
