# 项目资产原型

入口：左侧“项目资产”或 `http://127.0.0.1:5173/#assets`。

## 页面与数据

- 沿用公共导航、顶部、字体和品牌紫 v4。主区域为平铺文件列表，分类、阶段、路线、确认状态、生成方式组合筛选，搜索文件名、摘要、标签及可解析正文。
- 默认10份资料；重点突出SOP当前采用版与修改草稿。420–440px快速预览侧栏可展开为文档工作区，文档对话按需打开；项目主Agent为独立弹窗，不与文档对话并列占屏。
- `source-content.js` 是指定 outputs 目录下 SOP、formulations、evidence 的只读内容副本；PDF副本位于 public/assets/project-files/sop.pdf。未改写原始来源。候选设计原文与演示确认记录明确分开。
- 资产使用稳定ID。新版本、重命名、对话入口与任务往返均保留同一身份。数据位于 `synmat-project-assets-v1`，不覆盖项目流程或任务工作台的独立进度。
- R3记录初始未提交；若概览快照已登记报告，展示其交付状态，不据此新增实测数据或判定通过。

## 可操作场景

- 文件列表搜索/组合筛选、清除与空结果，选择及批量分类、下载可用文件、移除未引用资料。
- Markdown目录、正文查找、表格、只读历史、新草稿编辑；CSV示例表格和JSON格式化。Word/PPT保留附件和关联，说明未加载原件/不支持内置编辑。
- PDF提供真实本地副本下载和可选浏览器内嵌。因内嵌PDF在部分IAB环境不显示，默认用明确标注的同源Markdown阅读视图，不能称作PDF版式预览。
- 空白Markdown与本地AI示例起草，可选具体输入资料与版本，直接保存到资产集合。AI为预设响应，不执行检索、材料推理、Skill或多Agent调用。
- 文档提问只回答；明确修改请求先形成内容差异，确认保存新草稿。新草稿不覆盖历史、不切换任务引用、不自动完成任务。
- 针对具体版本提交/确认，即使出现更晚草稿，确认对象仍固定。确认与采用独立；采用先形成变更草稿，负责人再次确认后仅更新该任务引用，不重启实验。
- 来源、任务、路线、输入/输出/参考关系；可跳转实际任务工作台，再返回同一文件和版本。取消普通关联先确认；固定输入的解除登记待确认请求并保持当前引用。
- 重命名、分类、标签、重要标记、归档；回收区可恢复。被任务固定采用、被其他文件引用或已交付的文件不能直接移除。
- 演示负责人、成员、只读成员权限；确认仅负责人可操作。受限评审附件可展示无权预览状态。不是生产ACL。
- 重置同步恢复文件、版本、引用、重要标记、回收区及聊天；不重置其他页面。

## 本地文件边界

文本上限2MB，UTF-8或JSON解析失败仍保留文件并提示，不能搜索失败正文。二进制原件仅会话保存，刷新后保留元信息和版本，下载需重新加载对应原件。重名须明确选择新独立文件或已有文件的新版本，取消不添加。下载时使用当前选择版本的正文/原件，不能用最新二进制冒充历史。

- 既有开发服务、项目流程、草稿、阶段进度、概览测试一并运行，共24项通过。
- 浏览器检查：1280/1440列表、S2+R3筛选、长文与差异、确认/采用草稿、上传本地附件、Office边界、回收恢复、只读受限、关联任务往返、窄屏文档对话。
