# 产品需求文档

## 1. 文档信息

| 项目 | 内容 |
| --- | --- |
| 产品名称 | SynMatAI 新研智材 |
| 文档版本 | V1.0 · 2026-11-04 |
| 当前阶段 | 高保真交互原型；品牌紫色V4、项目流程V3 |

## 2. 产品目标

- 将材料研发方案组织为可查看、可调整、可交付的项目流程。
- 在同一工作区连接人员、Agent、任务、文件、实验和计算模拟。
- 演示“新建项目→需求确认→调研→立项→SOP确认→研发→反馈与后续规划”。
- 所有AI回复、自动生成、计算运行及审批均为本地演示。

## 3. 用户角色

| 用户 | 典型任务 |
| --- | --- |
| 项目/研发负责人 | 确认需求和方案、安排工作、复核结果、管理成员与后续规划 |
| 研发成员 | 调研、整理文档、讨论方案、完成TODO与交付 |
| 实验操作人员 | 登记制备、批次、样板和异常 |
| 测试人员 | 提交测量、补充缺项、追加修订 |
| 只读成员 | 浏览授权范围内的项目、文件与实验记录 |

角色与身份切换仅用于前端演示，不代表正式权限控制。

## 4. 核心概念

| 概念 | 定义 |
| --- | --- |
| 项目 | 独立保存基础信息、流程、对话、资产和实验的研发空间 |
| 阶段 | 项目立项、研发、量产；研发可形成多轮阶段 |
| 子阶段 | 阶段内的进展划分，如路线比较、长期确认、客户准入 |
| 工作包 | 围绕一个目标组织的执行单元，包含TODO、输入与交付 |
| TODO | 工作包内部可分配、可讨论、可完成的具体任务；本文统一称TODO |
| Agent | 对话中的具名协作角色；当前以预设内容演示 |
| 文件资产 | 有稳定身份、版本、来源和关联关系的资料或产物 |
| 项目流程 | 查看与编排阶段、工作包、TODO及文件关系的画布视图 |
| 工作台 | 执行当前工作包/TODO的对话与专业工作区 |

工作包不是TODO；文件不是执行任务；“结果文件”任务类型也不等于实际文件节点。

## 5. 完整业务流程

| 顺序 | 用户操作 | 系统反馈与推进条件 |
| --- | --- | --- |
| 进入项目列表 | 打开产品或返回列表 | 首次无指定页面时展示列表；保留内置示例与本机项目 |
| 新建项目 | 填项目名称、负责人、可选简介 | 创建独立项目，进入需求确认工作台；研发、量产保持待规划 |
| 补充基础信息 | 在对话中描述需求、约束、预期产出 | 生成《项目基础信息.md》草稿；明确确认并同意启动后，完成需求确认、进入技术调研 |
| 技术调研 | 分别确认两项并行TODO | “梳理技术路线与证据缺口”“形成技术调研报告”同时启动；全部完成后进入项目立项 |
| 项目立项 | 完成“立项材料准备” | 完成工作包并进入SOP审批；不新增“组织立项审批”默认TODO |
| SOP审批 | 确认“SOP项目工作流” | 本地记录确认，生成首个研发阶段；同时启动全部就绪根工作包 |
| 研发 | 按依赖执行工作包、TODO，交付文档及实验记录 | 展示条件验证、路线比较、因子筛选、工艺优化、长期确认、客户准入；保留原型既有节点名称 |
| 客户准入 | 收集用户反馈，完成阶段任务确认 | 保存反馈，标记“下一研发阶段待规划”；不自动创建第二阶段 |
| 后续研发规划 | 后续明确决定启动 | 当前不自动生成；启动入口与规则待确认 |
| 量产 | 查看阶段入口 | 新项目仅展示待规划占位；现有小试/中试/量产示例不作为新项目自动生成规则 |

浏览、上传、生成示例文档和切换视图均不等于完成工作。

## 8. 工作流规则

| 规则 | 确定要求 |
| --- | --- |
| 层级 | 项目→阶段→可选子阶段→工作包→TODO；项目阶段当前不可编辑 |
| 编号 | 阶段P1/R1/L1；子阶段R1S2；工作包P1T3或R1S2T1；TODO-001，完整引用P1T3-TODO-001 |
| 稳定性 | 名称变化不改编号；同父级按最大序号递增，不复用删除编号；T11等旧示例编号兼容 |
| 三层画布 | 全局：阶段及子阶段；阶段：工作包；任务：工作包内部TODO与文件 |
| 节点类型 | 快速创建/编辑使用结果文件、实验节点、模拟计算、分析节点、调研节点、临时任务；文件与临时对话另有语义 |
| 文件节点 | 仅表达资料传递，无执行状态、负责人和执行Agent；来源由产出任务确定；不得手改文件来源或向只读输入写产出 |
| 状态 | 工作包/阶段：待开始、进行中、已完成；TODO：未开始、进行中、受阻、已完成；实验单独使用五态，不强行互转 |
| 依赖 | 真实执行依赖采用全部前置完成规则；穿透输入/结果文件，检查上游真实任务；上下文引用不算执行依赖 |
| 连线校验 | 拒绝自连、重复、循环及阶段内编辑器的跨子阶段连线；虚拟输入只发起、输出只接收 |
| 并行启动 | 工作包激活时，所有无未完成前置的TODO同时启动；完成节点后，同时启动全部就绪下游，工作台仅展示其中一项 |
| 跨阶段 | 保留前序子阶段完成条件；SOP确认才生成研发内容；导航与画布建议线不改变业务状态 |
| 聚合完成 | 全部执行TODO完成→工作包完成；全部工作包完成→所属子阶段/阶段完成；文件、临时对话不计执行进度 |
| 交付与完成 | 交付要求与实际文件分开；缺关联文件需提示，但原型允许人工明确确认工作完成，不补造文件或实验通过 |
| 已完成保护 | 内容、负责人、删除及既有依赖只读；允许作为新下游连线起点，不接收新上游；上传/登记产物和对话仍可用 |
| 新建与删除 | 新工作包仅一个默认TODO；删除未完成任务清理连线，不删既有文件；移出实验节点保留ELN；删除不自动重接依赖 |
| 视图一致 | 画布、工作台、对话导航使用同一工作包/TODO身份；选择、缩放、切层和浏览不改完成状态 |

## 9. 任务类型与工作台

任务分类与画布节点类型是两套当前存在的呈现口径，不能把二者当成两份任务数据。执行方式单独选择；实体实验固定人工，模拟计算使用模拟执行。

| 任务类型 | 执行方式 | 默认/现有Agent | 右侧工作区 | 交付物 |
| --- | --- | --- | --- | --- |
| 调研 | AI或人机协作 | 调研/技术调研Agent；文献类可用文献调研Agent | 对话资产、报告文档 | 调研报告、证据线索 |
| 文档整理 | 人工、AI或协作 | 资料整理Agent；具体任务可另指定 | 文档预览与草稿 | Markdown等文档 |
| 计算模拟 | 模拟执行 | 模拟计算Agent | 模拟工作台 | 演示结果、计算报告 |
| 实验 | 人工，AI辅助 | 实验Copilot辅助，不代替执行人 | 已关联实验ELN | 制备、批次、样板及异常记录 |
| 测试 | 人工，AI辅助整理 | 无全局固定Agent，沿用任务配置 | 已登记测量在ELN；整理工作看文档/资产 | 测量记录、报告 |
| 自定义 | 按任务配置 | 无统一默认，需指定负责人 | 默认对话与资产；明确关联后打开专用区 | 配置的交付要求及实际文件 |

分析类快捷入口使用数据分析Agent。DOE快捷入口仅为现有原型入口，不代表已具备实验设计能力；其类型冲突见第13节。

## 10. 原型数据与演示规则

| 内容 | 行为与刷新要求 |
| --- | --- |
| 项目数据 | 按项目隔离保存流程、任务、对话、文件、实验和阶段进度；刷新恢复，切项目不串数据 |
| 入口恢复 | 无指定页面首次进入列表；刷新指定工作台恢复有效当前节点；失效流程定位回退全局 |
| 新项目 | 初始仅立项工作；不预生成研发/量产任务，不预填示例实验；重复触发不得重复造阶段/文档 |
| AI与流程生成 | 使用预设内容和短演示状态；不宣称真实检索、Skill执行、多Agent调度或任意SOP解析 |
| 文件 | 文本及版本按支持范围本地保存；二进制原件、工作台会话上传不承诺刷新后可用，保留元信息不冒充原件 |
| 编辑与偏好 | 流程草稿、坐标、消息、输入草稿、文档版本及演示卡位置保留；撤销/重做只承诺当前会话 |
| 示例与重置 | 来源方案只读；各模块重置仅影响明确的本项目演示范围，不改来源文件或其他项目 |
| 汇报与审批卡 | 可展示进度叠加和示例审批结果；不据此直接改变TODO、实验或项目放行状态 |
| 模块差异 | 新项目概览读取实时本地数据；内置示例概览仍有独立快照，不把快照数值当实际执行结果 |

## 11. 非功能要求

| 要求 | 可验收行为 |
| --- | --- |
| 页面布局 | 品牌紫V4；70px主菜单；对话与右侧工作区独立滚动，输入区可持续操作 |
| 空间分配 | 切入项目流程默认对话/画布各半；实验/模拟预览约80%、对话约20%，均扣除对话列表与分隔条 |
| 响应式 | ≤740px对话列表用浮层；不覆盖桌面折叠偏好；窄屏表单单列、导航可横滚，关键按钮不被截断 |
| 画布可用性 | 切层或调整栏宽后适应全图；可缩放平移；工具栏、输入侧栏与Agent快捷区不重叠 |
| 状态一致性 | 同一对象跨入口即时一致；文件与临时对话不混入执行进度；选中态与执行态区分 |
| 操作连续性 | 切层保留对话草稿；连续完成进入统一工作台；浏览器前进/后退不落入旧工作台 |
| 可理解性 | 长标题可查看全文；已有/预期/草稿/确认版/演示明确区分；空阶段显示待规划，不显示空白故障感 |
| 可访问性 | 按钮有名称；键盘可操作导航、选人、关闭浮层与替代拖放；尊重减少动态效果偏好 |
| 本地可靠性 | 提交避免重复创建；未保存ELN离开需处理草稿；失败保留可恢复输入，不以成功提示掩盖缺失 |
