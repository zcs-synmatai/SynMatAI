# 项目流程V2：无限画布交互原型

> 2026-10-28 已冻结：回收站“工作流程V2”打开独立备份；主导航“项目流程”使用复制后的V3继续开发。最新版本边界见 `project-flow-v3.md`。

入口：主菜单“项目流程V2”或 `http://127.0.0.1:5173/#project-flow-v2`。原“项目流程”继续提供文档式布局，方便对照；共用业务数据，不改变冻结V1。

## 界面组织

公共导航与项目阶段沿用品牌紫v4。画布主区以任务节点和曲线依赖为核心。顶端左侧为“子阶段编号/名称＋技术路线”；下方悬浮工具条提供新增节点、指针/抓手切换、节点搜索定位、撤销与重做，原右上按钮框移除；原大标题栏、局部子阶段下拉和项目资料按钮移除。项目阶段顶栏仍可切换子阶段，名称入口可查看阶段说明。

Supervisor Agent 固定在左侧，上方对齐子阶段/技术路线、下方对齐布局工具。三者同宽380px，窄视区330px；Agent上下间距12px，消息独立滚动，输入固定底部，撑满两栏之间高度。Agent不随画布平移或缩放，不可拖动，仍可收起。Agent不计入节点布局和缩略图。

## 节点与连线

- 节点顶部编号、状态、选择框和拖动柄是独立操作区：点击选择，不跳转、不显示悬浮信息；选择框支持逐项多选，Ctrl/Meta/Shift+点击支持增减选择。节点正文单击/Enter进入对应工作台，T20仍使用原计算模拟工作台。右键/Shift+F10打开节点详情。人员按钮、拖动柄与连接点独立操作。
- 节点四边各有连接点，默认隐藏，鼠标悬停节点时显示，移开后隐藏；拖线命中目标节点或键盘聚焦连接点时也显示，节点选中本身不使连接点常显。从源节点拖至目标连接点可新增依赖，拖动中显示预览、目标高亮；也支持依次用键盘Enter选择源/目标连接点。记录所选端点，拖动节点后曲线随动。
- 所有连接采用三次贝塞尔曲线；现有证据关系保留虚线，新增关系默认为实线。拒绝自连、重复、循环、跨子阶段及已完成节点关联修改。释放到空白时，在释放位置弹出任务类型菜单：调研节点、实验节点、计算节点、审批节点、分析节点、临时任务。选择类型打开新增表单，预选来源节点为前置，保留源端点方向；确认后创建并连接。取消表单或按Esc关闭菜单不新增节点。释放至已有节点连接点仍直接增加连线。
- 单击连线浮出上游交付文件列表、已交付/待交付状态；没有真实文件则展示预期交付名并标为待交付，不打开文件、不显示长篇Gate条件。右键未锁定连线进入编辑。
- 悬停节点约320ms浮出负责人、交付物、工作要求。优先位于节点下方，空间不足时翻转，内容可滚动；指针可进入卡片查看，不触发工作台跳转。
- 节点视觉位置可由右上角拖动柄调整，不改变定义/依赖。自动布局恢复视觉位置，并根据每张卡片实际高度对齐同排节点的垂直中心，避免高低卡片产生微小弯折。六点手柄单击选中，拖动移动，不触发工作台或详情悬浮。拖动时匹配其他节点的左右/上下边缘与中心，在8px屏幕距离内吸附，显示品牌紫虚线参考线；多选整体吸附并保持相对位置，Alt暂时禁用吸附，松手后参考线消失。

## 画布操作与文字

默认指针模式，空白拖动框选节点，不平移画布；抓手模式空白拖动平移。工具菜单支持V切换指针、H切换抓手；空格+拖动或中键临时平移；滚轮平移，Ctrl/Meta+滚轮围绕指针缩放，Shift+滚轮横移。缩放范围25%–160%。聚焦画布后方向键平移、+/-缩放、0回到100%、Home或双击空白适应。底部提供相同操作、当前任务定位与自动布局，右下角缩略图定位视区。

Agent不拦截正文/输入框滚动，画布视角不会跟随对话滚动变化。适应和定位按固定Agent栏外的可用区域计算。节点宽244px，标题17px、辅助14px、状态12px；连线说明默认16px并按缩放补偿到至少约12px屏幕字号。

多选或框选后显示共同外框，上方浮出“添加到 Chat / 新建任务”菜单。前者将节点引用加入Supervisor Agent输入区，供用户继续提问，不自动发送；后者预选全部选中节点为前置节点，后置默认为阶段结束。已完成节点可作为新任务的交付来源，原节点定义仍锁定。添加到Chat成功后清除选择；新建必须确认成功后再清除，取消或校验失败保留选择。新节点优先靠近前置节点右侧、或拖线释放位置，预留60px避让间距；冲突时搜索相邻空位，不移动已有节点，完成后定位新节点。新建操作可撤销/重做。

快捷菜单支持单个/批量删除：确认框列出待删除节点及关联连线数量，已完成节点始终保留；混合选择仅删除未完成节点。删除同步清理关联连线，不自动跨接上下游，允许清理指向被删节点的已完成来源连线，完成节点定义/负责人不变。删除成功清除选择，可撤销/重做。节点顶部整行（含留白）可选择节点，不跳转、不出现详情悬浮卡片或浏览器原生提示。

选中节点的所有入线和出线显示顺方向光效；使用固定屏幕长度20px的光段，间隔130px，不按路径总长度归一化，缩放时同步补偿光段长度和宽度。减少动态效果设置下停用动画。

## 数据与验证

节点定义、关系、状态、交付、负责人、任务工作台继续复用项目流程。相机、工具模式、节点选择和节点坐标按阶段/子阶段保存于 `synmat-flow-canvas-v2`；现有坐标迁移保留，Agent旧坐标不再使用。没有接入真实AI、后端或科学计算。

`node --test scripts/flow-canvas.test.mjs` 覆盖锚点缩放、负坐标适应、位置保持、四边端点曲线、最近连接点、正反向框选、选择外框、固定光效长度、新节点位置避让、异高卡片中心对齐与单/多选拖动吸附；删除保护及历史恢复由 flow-draft.test.mjs 验证。全部现有测试同时运行。浏览器检查拖线新增/撤销、已完成端点禁用、Agent固定对齐、悬浮信息、文件列表浮窗及节点工作台入口。

## 返场进展汇报演示

顶栏“交互演示”按钮模拟隔一段时间返回项目：打开研发/S2画布，Supervisor Agent主动报告T21已完成、T22进行中，并给出“路线比较样板制备方案”“匹配空白与记录要求”两项T22示例审批卡片。点击卡片进入快速审批，查看示例文件列表、确认要点，支持通过、填写原因退回及稍后处理；反馈更新卡片，不能重复处理。每次重新演示恢复两项待确认。

汇报时居中突出T21/T22及两者连线，其余节点弱化；任意后续点击移除高亮并恢复之前视角，汇报对话仍保留。审批卡片点击同时退出高亮并打开审批。演示不覆盖任务完成状态、不放行下游、不发起真实审批或AI调用。

节点编号使用16px起的高对比标识，按画布缩放适度补偿；顶栏按选择框、编号、状态、手柄组织，标题、负责人、范围、工作台入口依次排列。沿用品牌紫v4及语义状态色，连接点仍仅悬停显示。返场审批状态规则由 `flow-return-brief.test.mjs` 覆盖。

返场汇报动效：消息以两字/38ms逐渐显示，先报告任务进展，再提示待确认事项，两张审批卡片以260ms间隔出现；汇总期间显示轻量三点提示。T21/T22各有一次柔光扫过、两轮呼吸光晕，两者连线显示有限时长的方向光效，约7秒后静止。任意点击立即停止动效、补齐消息并恢复视角；重播、重新渲染或关闭页面会清理定时器。系统启用减少动态效果时直接显示完整消息，关闭扫光/呼吸/方向动画。

Agent面板视觉：面板标题保留Supervisor Agent，汇报消息标题改为“项目进展”及“刚刚更新”，避免重复身份标题。初始欢迎说明在出现返场汇报后隐藏，真实对话保留；进展用一条轻量状态带串联T21/T22。两项审批使用文件图标、标题/材料数、状态/审批入口三列对齐，弱化边框并保持整项可点击。输入区采用中性色边框和轻底色，保留原+、命令、上下文和发送交互。矮窗口压缩卡片副信息与间距，优先同时露出汇报文字、进展和两项审批。

指针和抓手模式下，节点顶部操作行（编号、状态及留白）均可单击选择，选择框仍支持多选。抓手平移不接管该操作行；正文/空白按原模式平移，六点手柄仍移动节点。每次新按下清理上一次拖动的点击抑制标记，避免拖动画布后首次选择失效。

主导航入口现名“项目流程”，路由仍为 #project-flow-v2。抓手模式下单击节点正文同样进入工作台（含标题、范围和底部入口），按下移动超过3px仍按平移处理，不误跳转；顶部选择行、负责人及六点手柄独立操作，空格/中键临时平移不触发进入。

最新交互：卡片普通区域（标题行、正文、范围、底部提示）单击选中，双击打开对应节点。项目流程打开工作台，任务画布打开节点详情/文件预览；两种工具模式一致。选择框、负责人、对话入口、连接点、六点手柄保持独立，不因双击误打开。抓手按下时由原卡片捕获指针，既保留平移又保留原生双击事件；不再以程序化单击模拟进入。拖动超过3px抑制点击。
