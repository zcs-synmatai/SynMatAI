# 产品事实

## 统一产品概念

| 概念 | 定义 |
| --- | --- |
| 工作流 | 项目推进时推荐采用的流程，表达工作之间的依赖和产出流转。 |
| 阶段 / 子阶段 | 项目主要进展的阶段划分，用于定位项目推进到哪里。 |
| 工作包 | 阶段或子阶段工作流中的节点，围绕一个工作目标组织执行内容。 |
| 任务、实验等 | 工作包内部的具体执行事项，可由人工、Agent 或人机协作完成。 |
| 任务工作台 | 进入和执行工作包的工作入口，包含任务、实验、文件、对话与工作包内部流程。 |

例如：“研发 / 路线筛选”是阶段定位，“制备路线比较样板”是工作包，工作包内包含具体任务与实验。主导航原“阶段任务”入口统一称为“任务工作台”。此处确立后续开发术语，本次仅修改所要求的主导航名称，既有数据标识和路由沿用。


用户提供的数值模拟工作台原型。保留项目导航、当前任务定位、左侧 Copilot、右侧模拟流程、节点模型窗口、手动与 AI 辅助修改、节点参数、待办和文件资产。
平台为浏览器，交付静态 HTML 交互演示。真实计算与 AI 服务不在本次范围内。


项目状态：市场分析、项目立项、研发、量产；当前研发。
研发子阶段：实施条件验证、路线筛选、因子筛选、工艺窗口优化、耐候与老化、客户验证；当前路线筛选。
路线筛选包含计算模拟、建立批料与施工窗证据、制备路线比较样板、初始性能测量、沸水验证、配对擦伤验证、路线选择。
跨尺度依赖：三种材料分别计算热导率，输入宏观构件对应材料区域，再提交调度和结果分析。
