# 后续原型开发上下文

本文件保留后续页面需要的产品事实与已确认决策；用户最新需求优先。

本研发流程开发对话已整理为[项目级记忆入口](../../memory/README.md)，后续按角色和使用流程细化时，按需阅读其中的研发工作台记忆与待确认清单。


## 当前任务与入口

- 计算模拟与实验类型任务进入统一工作台时，右侧专用预览区默认占可用工作区约 80%，AI 对话区约占 20%；项目内对话列表与分隔条从可用宽度中单独扣除。专用预览只保留统一工作台顶部导航，嵌入的旧计算工作区不再重复显示一级导航。
- 项目流程的任务视图直接编辑工作包内同一份 TODO 数据：未开始和进行中的任务可从节点浮窗编辑或删除，字段与工作台 TODO 编辑器一致；删除同步清理关联画布连线，但不删除既有文档。已完成任务保持只读、不可删除。
- 任务节点快速编辑浮窗采用 390px 宽、最高 480px 的自适应布局；视口下方空间不足时自动向上展开。浮窗直接编辑标题、节点类型、执行方式、负责人和交付要求；“编辑完整信息”入口已移除，只保留保存、取消与删除。节点类型统一为：结果文件、实验节点、模拟计算、分析节点、调研节点、临时任务。
- 用户新建的工作包默认只包含一个 `TODO-001`“默认任务”节点；交付要求仅作为工作包信息，不再为每条交付自动批量生成内部任务。既有工作包和演示工作包的数据不迁移、不重写。
- 任务节点的非模态属性浮窗在桌面端使用 390px 宽度，并根据节点上下可用空间在最高 480px 内自动放置；快速属性的“取消 / 保存修改”与“删除任务”分层，所有操作文字保持单行。窄容器下字段改为单列，危险操作不与主保存按钮混排。

- 任务工作台对话栏顶部随当前 TODO 更新：主标题为“Agent 名称 - 当前 TODO 名称”，副标题为“工作包编号-任务编号”（例如 `P1T2-TODO-001`）；切换 TODO 时两行信息同步切换，长标题保持单行省略并可悬停查看全文。连续完成工作包并进入下一工作包时，工作台直接选中首个进行中的 TODO，不先恢复该工作包的任务总对话；消息区不再重复显示面包屑路径小标题。

- 项目立项的 P1T2“技术调研”包含两项并行 TODO；P1T3“项目立项”仅保留“立项材料准备”一项，原“组织立项审批”默认节点已移除。工作台完成按钮按当前对话编号直接更新原始 TODO；工作包内全部 TODO 完成后同步工作包状态并进入下一工作包。
- 任务编号统一使用“工作包编号-TODO-三位序号”显示，例如 `P1T3-TODO-001`、`T11-TODO-002`；内部稳定编号保持 `TODO-001` 形式。T11 采用明确的六任务演示模板并连续编号：条件梳理后并行启动三项实验和一项计算模拟，最后汇总实施风险清单。旧的冗余节点不保留编号空洞，已有本机项目首次打开 T11 时一次性更新为该模板。
- 新建实验类型 TODO，或将未完成 TODO 修改为实验类型时，自动创建一条本地演示实验记录并写入任务关联。双击实验节点或从节点浮窗进入 Agent 协作时，统一进入任务工作台，右侧同时打开“节点资产”和“实验 ELN”两个页签；计算模拟节点同样打开“节点资产”和“模拟工作台”两个页签。自动创建只表示原型中建立实验容器，不代表方案已确认或真实实验已执行；模拟工作台也不代表已接入真实计算服务。
- ELN 作为工作台页签嵌入时，不显示独立实验详情页的“返回实验列表 / 实验编号 / 本机更新时间”导航行；页签本身承担返回和关闭入口。独立实验详情页继续保留该导航信息。
- 项目流程画布复用工作台对话栏时，消息区不再重复显示“阶段 / 子阶段 / 工作包”上下文标题；当前位置只由对话栏顶部面包屑表达。
- 项目概览底部提供试验版“核心指标达成路径”管理汇报图，将材料指标的基线、关键工作完成时间、当前值、目标值和待验证计划合并展示；演示数值明确标注为示例，不代表真实实验结果。

- 工作流执行遵循依赖就绪规则：完成节点后，所有前置依赖均已完成的下游分支同时进入“进行中”，不按数组顺序只启动第一项。首次生成研发阶段时同样启动全部无未完成前置依赖的根工作包；工作台只打开其中一个进行中的节点，不影响其他并行分支状态。
- 文件节点只表达输入、产出和传递关系，不参与“待开始 / 进行中 / 已完成”的执行状态计算。判断 TODO 是否可启动时，应穿透输入文件和结果文件，只检查真实的上游任务；工作包进入进行中后，所有任务前置条件已满足的 TODO 同时启动。

- 演示说明按页面层级严格隔离：工作台仅匹配完整的“工作包编号-TODO编号”，不使用工作包通配内容；项目流程只读取全局、阶段或工作包层级说明，不读取 TODO 级说明。没有精确 TODO 配置时回退到工作台默认说明。

- 从主菜单进入“项目工作区”时，按项目流程顺序打开第一个“进行中”的任务节点，不沿用旧计算模拟工作台作为兜底。若项目没有进行中节点，再回退到项目记录节点或第一个未完成节点。
- 顶栏流程导航中的空阶段或空工作包必须显示“— 待规划”占位，不保留无内容的空槽，避免被误认为加载或渲染故障。
- 顶栏流程导航保留单击同层定位；任务视图双击工作包图标返回该工作包所属阶段视图，阶段视图双击阶段图标返回全局视图。图标提示需明确双击后的目标层级。
- 新建下游节点菜单不再提供审批节点和会议节点；提供结果文件、实验节点、模拟计算、分析节点、调研节点与临时任务。任务工作台中的同类菜单同步移除审批/会议并增加模拟计算，已有审批和会议节点保持不变。
- 工作流任务视图在流程导航下方提供独立的 Agent 快捷工具层（分析、调研、DOE），并为画布节点预留顶部空间，不与流程导航重叠；支持点击或拖入画布直接创建对应 TODO，拖动过程显示“安排 Agent 工作”反馈。进行中的内部任务按稳定的演示分布显示“Agent 工作中”旋转标识；同一项目刷新后分布不跳变，减少随机闪烁。该动效只表达原型中的协作状态，不代表真实 AI 服务已执行。

- 产品首次打开且 URL 未指定页面时进入项目列表 `#projects`，不再自动恢复项目工作台。显式访问工作台、项目流程及其他功能路由时继续进入指定页面；刷新 `#workspace/task` 仍恢复当前项目和节点。

- 新项目完整演示流程已补充项目列表入口：项目行提供“项目工作台”和“项目流程”两个入口，两者进入同一个项目工作区页面的不同状态；新项目从立项阶段的“需求确认 → 技术调研 → 项目立项 → SOP 审批”推进。技术调研形成项目基础信息和技术调研报告，SOP 审批后生成首个研发阶段；客户准入收集反馈并完成阶段任务确认后只记录“下一研发阶段待规划”，不自动生成第二阶段。各项目的流程、对话、资产和阶段数据按项目隔离，研发与量产在触发前不预生成工作包或任务。完整说明见 `docs/demo-project-flow-requirements.md`。

- 任务工作台导航与项目流程V3统一：移除旧项目状态横条及标题下工作包列表，顶部以单条紧凑缩略流程导航展示全项目工作包链；右侧“阶段 / 工作包”切换导航层级，阶段包含子阶段，选择后浏览该阶段工作包，再点击进入工作台。复用FlowOverviewDock及FlowHierarchyModel.packageOverview，名称、状态、自定义工作包和依赖读取项目流程的同一份定义；当前工作包紫色高亮，悬停/聚焦提示全文，支持横向滚动与键盘。标题点击定位当前工作包，“返回项目流程”打开对应阶段；导航不改写执行状态或依赖，计算工作包保持计算界面。

- 项目流程 V3 的任务视图恢复从内部节点连接点拖线并在空白处释放创建下游任务：输入节点及普通任务/文件节点均可作为来源，输出节点不可作为来源；类型菜单只提供任务节点类型，不提供结果文件。创建的新待办与来源连线一并保存在所属工作包，节点优先落在释放位置，既有画布位置继续保留。计算模拟演示内部保持只读。

- 项目流程 V3 的任务视图双击内部节点直接打开对应工作界面：普通任务进入所属工作包的专属对话，右侧默认显示“本对话产生的资产”且不自动打开关联文档；文件节点才直接在文档页签打开文件。实验与模拟计算节点不再跳出统一工作台，右侧以多页签并列显示节点资产与 ELN/模拟工作台；从节点的 Agent 协作入口进入时保持相同行为。阶段视图双击工作包仍先进入任务视图；本地原型创建实验容器或模拟预览均只用于交互演示。

- 项目流程 V3 的层级切换不得在触发它的单击/双击事件栈内同步替换画布，需延迟到下一帧完成挂载、顶栏和画布适应；双击内部节点进入工作台时，先完整卸载流程画布但保留当前路由，再由统一工作区控制器一次切换到 `#workspace/task`。画布相机必须在节点可获得焦点前初始化，快速双击不得停在流程与工作台之间，也不得因异常返回旧版工作台。
- 浏览器历史中若仍残留旧任务入口 `#task`，加载或后退命中时必须按项目的 `lastRoute` 恢复统一工作区：最后位于项目流程则回到 `#workspace/flow` 的对应上下文，最后位于工作台才按 `currentNodeId` 恢复 `#workspace/task`；不再显示旧计算工作台作为兼容回退页。

- 项目流程 V3 任务视图两侧切换在当前阶段首个或末个工作包处继续跨阶段：左侧进入上一阶段最后一个工作包，右侧进入下一阶段第一个工作包；只有整条项目工作包链的起点和终点禁用方向按钮。切换保留水平滑动并重新适应工作流画布。

- 项目流程 V3 的任务视图顶部缩略导航展示完整项目阶段链的工作包流程，可横向滚动；切换时当前阶段居中聚焦，其他阶段弱化但可直接点击，阶段间竖线与节点垂直居中。顶栏默认透明，悬停或键盘聚焦才显示半透明毛玻璃背景。阶段及任务画布的虚拟输入/输出节点使用仅含名称的紫色胶囊标记；单独选中时联动对应文件侧栏，不显示节点操作快捷菜单。

- 项目流程 V3 顶部导航合并为单条半透明毛玻璃浮层：左侧是阶段缩略流程，右侧用全局、阶段、任务三个图标控制查看深度；图标保留品牌紫选中态、悬停及键盘聚焦文字提示，不再显示两段独立条框。

- 项目流程 V3 的全局、阶段、任务视图及相邻阶段/工作包切换后，默认适应当前整张工作流画布；在缩略导航与两侧交付栏布局完成后重新计算全部节点和连线边界。用户随后仍可手动缩放、平移或使用“当前任务”单点聚焦。
- 项目流程 V3 阶段视图只新建工作包，末级任务在工作包内创建。输入/输出虚拟节点只显示极简名称；输入可向工作包发起连线或直接创建工作包，输出只接收连线；单独选中虚拟节点不显示批量菜单并高亮对应文件侧栏。上游已有文件可拖到未完成工作包建立本地文件引用。

- 全局视图从项目立项开始，连续展示项目立项、研发阶段、量产；新建项目不再创建或显示市场分析大阶段，项目立项编号为 `PH1`。研发阶段包含原六个子阶段，其中客户准入承担本阶段反馈收集和后续阶段规划；不在研发阶段外另设反馈节点，也不预置第二研发阶段。只有未来明确决定启动后，新的研发阶段才进入全局视图。阶段与任务视图画布不折叠，工作包依赖保持不变。阶段视图左右窄栏顶部可点击进入上一/下一阶段，使用水平滑动过渡；起点/终点禁用对应入口，文件图标仍独立预览。

- 新项目尚未生成研发或量产内容时，顶部流程导航的阶段标题保持为“研发”“量产”，阶段内占位节点统一显示“待规划生成”；状态不写入阶段名称。


- 项目流程 V3 采用三层无限画布：阶段流程（项目阶段及子阶段）、工作包流程、工作包内部。移除项目名称/阶段状态横条，Agent 常驻左侧满高；下钻时保留对话和输入草稿。右上角“全局 / 阶段 / 任务”三项控制查看深度，顶部横向缩略图以紧凑节点间距展示当前视图的上层流程，仅缩略图容器使用半透明毛玻璃，画布保留原背景；小图标按鼠标邻近程度放大，聚焦显示名称和状态，点击定位或切换阶段/工作包。层级变化使用缩放过渡并尊重减少动态效果设置。第二层两侧窄栏为相邻子阶段输入/交付，第三层为相邻工作包输入/交付，不展开；窄栏从缩略图底边下方开始，宽度 56px（窄屏 52px），顶部居中箭头可切换前/后阶段或工作包，悬停或聚焦显示完整名称；文件仅显示图标，悬停显示文件名，已有文件与预期交付明确区分。内部层先只读复用已有待办/依赖/文件，未配置关系的虚线建议顺序不写入实际工作流；“打开工作台”继续原有操作。完整说明见 `docs/project-flow-v3.md`。

- 项目流程页面已进入 V3 开发：主导航“项目流程”使用 `/#project-flow-v3`，继续编辑当前 research-flow 源码。此前页面移至回收站“工作流程V2”，完整独立快照在 `apps/web/public/archives/workflow-v2/`，后续不在冻结目录修改；V2本机数据一次复制到独立命名空间，V3沿用原记录。入口、版本校验和数据边界见 `docs/project-flow-v3.md`。此为页面版本，不改全产品V1/V2编号。

- 从主导航或项目流程的所有工作包入口（包括双击、进入按钮与文件关联工作包入口）进入任务工作台时，统一显示工作布局，不读取旧的画布偏好。工作台只承载任务对话、待办、输入/产出、任务资产和文档预览；工作流画布只在“项目流程”一级状态展示。项目流程中的内部节点仍可直接打开工作台对应对话或文档；计算工作包保留任务自身的计算界面。

- 工作布局右侧不再展示完整待办清单，默认只汇总当前对话实际生成的草稿与交付资产；完整待办仍从对话工具进入。未打开文档时对话区自动占据主要宽度，打开文档后切换为文档预览区主导；关闭唯一页签时不销毁当前预览，而是将右侧折叠为 54px 的“工作区域”图标栏，恢复入口固定在右侧栏顶部，点击后恢复原页签、内容和宽度。多个页签仍只关闭当前页签。
- “本对话产生的资产”列表在尚未上传任务资料时增加一条待上传文件：文件名跟随当前任务或专属对话，状态明确显示“待上传”，行内“上传文件”按钮调用本地文件选择。选择文件后文件进入当前工作区的本次会话资产并替代待上传行；不代表真实后端存储。

- 恢复普通画布卡片任意非输入控件位置双击按类型打开：实验进ELN，文档/文件切工作布局并预览，审批显示流程及快捷审批，调研/分析切工作布局与专属对话。临时对话节点例外：双击不打开或切换，使用对话按钮。选中节点正文移动超过阈值才捕获指针；无移动的按下/释放保留点击目标与双击，实际拖动不打开节点。

- 对话入口统一使用左右对称的圆角气泡图标（居中尾部、等距三圆点），按钮零内边距与固定20px方形SVG避免挤压。临时对话卡片在类型标识旁增加同款切换对话按钮，悬停/键盘聚焦可见；点击切换左侧Agent对话，保留单击选中、双击打开及拖动语义。

- 切换节点同步模型、参数和对话上下文；任务标题及按钮吸顶，对话输入固定在 Copilot 底部，消息独立滚动；分子模型上下居中。
- 窄窗口下依赖图可横向滚动并提示。参数按模型信息、计算设置分组。
- 节点资产与待办从输入区上方展开；文件可选择或拖入对话。`+` 添加文件/上下文，反斜杠按钮选择技能/命令。
- 待办为文本编辑交互，含名称、状态、@负责人、时间、优先级；超期突出，收起时显示当前用户紧急数量。
- 资产示例顺序：`.xyz`、`.eln`、`.png`、计算方案 `.md`、当前节点配置 `.json`；对应分子、ELN、图片图标，不恢复重复示例。
