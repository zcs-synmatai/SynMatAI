# 任务工作台：画布、专属对话与返场汇报

## 范围与入口

- 非计算类型的阶段任务，在标题面包屑旁切换“列表 / 工作流画布”。计算模拟及 `taskType=计算节点/计算` 的任务不显示入口，也不恢复已保存的画布模式。
- 列表保留待办、任务资产及文档页签。画布复用 `FlowCanvasV2` 控制器、相机数学、端点连线、框选、拖动、吸附、定位、缩略图与工具切换，不复制另一套交互实现。
- 画布专有模型与文件语义位于 `workflow/task-canvas-model.js`、`task-canvas.js`；项目流程原行为不变。

## 节点、输入与产出

- 原任务待办与本子阶段明确实验是初始节点。新增支持文档、审批、会议、调研、分析；实验复用项目实验身份，通过项目实验登记，避免复制 ELN。
- 节点单击进入待办专属对话，右键或 Shift+F10 查看配置与操作。实验详情入口进入原 ELN；文档/普通待办可配置，也可由用户明确生成演示文档。
- 输入物、交付物两框固定在画布右侧，不随视角移动。输入物从任务资产关联，首次关联保存只读文本快照；取消关联只移除画布引用及相关连线，不改原文件。
- 产出由节点明确生成，保留 producer ID，作为独立文件节点和交付物文件展示；本地草稿同步到任务资产及原待办 outputs。输入文件不能接收产出，产出文件不能手动改写来源。
- 文件节点可以连接任务；任务也可直接连接任务，将其已产生的输出列入下游输入。未生成文件时保持待交付，不创建虚假文件、不启动实验或 AI。自连、重复和循环连接拒绝。
- 输入文件只读预览；节点生成文档可编辑草稿。实验数据仍由原 ELN 维护，不在画布制造实验结果。普通待办删除同步列表；实验只能移出画布，其 ELN 保留。已完成节点内容与既有关系受保护，但可作为起点新增下游节点或向外连线；禁止把新连线接入已完成节点。新增节点可以没有下游，形成敞口终态。
- 拓扑与输入快照保存在工作区 `taskCanvas` 字段；相机/坐标通过共享控制器以 `task/<workspaceKey>` 独立保存。画布修改提供会话撤销/重做；外部列表/文档修改使历史基线变化时拒绝覆盖。

## 待办专属对话

- 统一清单每行提供对话图标，画布节点正文同样进入该待办对话。左侧显示待办编号、名称与 Agent/人工负责人，支持返回任务总对话。
- 消息和输入草稿按工作区/待办 ID 隔离，保存在 `conversations`、`conversationDrafts` 中；旧 messages 迁移为任务总对话。切换待办、任务或视图不串用消息。
- 演示回复回到发送时的线程；普通待办生成的本地草稿关联其输出，已初始化画布则同时登记文件节点。实验对话只辅助解释输入与记录缺口，不代填或提交测量。

## 返场汇报演示

- 任务工作台的“交互演示”在任务总对话发起汇报；项目流程 V2 继续使用原项目级演示。
- 汇报包含明确编号的完成项、推进项、停滞风险和两个快速审批卡片。选取当前工作区的真实待办身份，完成/推进只叠加演示快照，不更改实际 todos、实验进度或阶段状态。
- 列表突出变动行，其余弱化；画布通过共享控制器突出同一节点。任意后续点击立即清除高亮并停止效果，保留汇报对话。减少动态效果设置下不播放动画。
- 卡片可进入快速审批，展示示例文件、确认要点与意见，支持通过或填写原因退回；结果仅更新演示卡片，不完成业务任务或放行实验。重播恢复两项待确认。

## 验证

`scripts/task-workspace.test.mjs` 检查输入身份、文件来源、循环/重复连线、仅传递产出、线程隔离及汇报不改实际状态。浏览器联调核对视图切换、输入只读、文档产出、连线、线程切换、返场高亮和审批。
