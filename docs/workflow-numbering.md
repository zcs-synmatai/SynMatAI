# 工作流编号标准

编号用于稳定定位流程对象，名称可修改，编号不随名称变化。新建对象按同一父级下的最大序号自动递增，不复用已删除编号。

| 层级 | 格式 | 示例 | 说明 |
| --- | --- | --- | --- |
| 阶段 | `P1` / `R1` / `L1` | `P1` | P 为项目立项，R 为研发轮次，L 为量产轮次 |
| 子阶段 | `<阶段>S<n>` | `R1S2` | 项目立项暂不拆子阶段；研发、量产按阶段内顺序编号 |
| 工作包 | `<阶段或子阶段>T<n>` | `P1T3`、`R1S2T1` | 在当前阶段或子阶段内递增 |
| 任务 | `TODO-<三位序号>` | `TODO-001` | 在当前工作包内递增；完整引用为 `P1T3-TODO-001` |

规则：

- 卡片显示自身编号；工作台、演示说明等跨层级引用显示完整编号。
- 新建工作包和任务时由页面自动生成编号，不再使用“自定义”或时间戳作为可见编号。
- 并行任务仍各自占用一个编号，编号不表示执行先后。
- 旧演示数据中的 `T11`、`S1` 等编号继续兼容；用户新建内容统一使用本标准。

## 模拟任务

“模拟”是任务类型和执行方式之一。模拟任务由“模拟计算 Agent”承载，在统一工作台右侧以“模拟工作台”页签展示现有计算依赖、模型配置和演示结果。当前原型只演示交互，不执行真实科学计算。
