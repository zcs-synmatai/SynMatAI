# 服务端规划（尚未实现）

先确认部署与科学计算运行环境，再确定后端语言、数据库和队列。
预期模块：身份与权限、项目阶段与任务、工作流节点及依赖、文件资产、待办、AI 会话、计算任务调度、结果索引。

接口范围草案：
- /api/projects：项目及阶段任务。
- /api/workflows：节点配置、连线、版本和依赖校验。
- /api/assets：上传、元数据、下载、节点关联。
- /api/todos：状态、负责人、截止时间和节点归属。
- /api/jobs：提交、状态、取消、日志及结果索引。
- /api/conversations：会话、文件引用和 AI 执行。

以上只有规划，不是已存在的 API。真实文件和计算结果应交由持久化存储管理；求解器通过独立 worker/adapter 接入。
